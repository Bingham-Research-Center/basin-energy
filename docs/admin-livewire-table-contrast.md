# BasinEnergy management tables: Rappasoft v3 theme

## Dependency and compatibility audit (November 2026)

The repository's committed `composer.lock` contains:

| Package | Locked version |
| --- | --- |
| `livewire/livewire` | `v3.7.15` |
| `rappasoft/laravel-livewire-tables` | `v3.7.3` |

These versions already support the relevant controls and customisation hooks.
`config/livewire-tables.php` correctly uses `bootstrap-4`, matching
the CoreUI 3 / Bootstrap 4 application. **No Composer upgrade is needed for
this design change.** Do not switch the package to Tailwind or Bootstrap 5
without upgrading the broader dashboard infrastructure and its tests.

The reference demo inspired the palette, alternating rows, badges, search
and filter controls, column selection and pagination. We deliberately reuse
the vendor's own Livewire markup and functionality, not screenshots or
copied vendor templates.

## Implementation

- `public/css/dashboard-tables.css`: scoped to `.brc-admin-data-table`,
  uses matched light and dark surfaces/text, compact toolbar controls,
  striped/hover/focus rows, pagination, responsive scrolling and readable
  dropdowns. Also honors reduced-motion preferences.
- `resources/views/backend/layouts/app.blade.php` includes the new
  stylesheet **after** CoreUI and `dashboard-theme.css`, with a versioned
  URL. The old contrast overrides moved out of the global dashboard theme
  stylesheet so they cannot conflict.
- `UsersTable` shows initial-based name avatars, timezone if set,
  account-type, Active, Verified and 2FA status pills. Existing name/email
  search, status filters, roles/permissions and authorization-protected
  account actions remain. The 2FA relation is eager-loaded to avoid one
  extra database query per row. Verification timestamp is retained in the
  Yes pill's title.
- `RolesTable` uses the same role-type and user-count pills.
- Broadcast newsletter and announcement tables use the same status pills
  while preserving the existing recipient progress bars, Livewire polling
  and editor actions.
- The Actions column cannot be hidden using the optional Columns control.
  Other user-selected columns can still be remembered by the package.

All dynamic names and labels in HTML fragments are Blade-escaped.
No custom JavaScript is required for sorting, search, filters, column
selection or pagination: these remain the package's native behaviors.

**Bulk actions are intentionally not added.** The screenshot shows that
feature in the Rappasoft demo, but BasinEnergy has existing
permission-guarded per-row user management actions; adding bulk
deactivation or deletion would be a separate permissions-sensitive
feature and should not be introduced just to replicate appearance.

## Included surfaces

- Admin > Access > Users (active, deactivated, deleted)
- Admin > Access > Roles
- Admin > Broadcast > Announcements
- Admin > Broadcast > Newsletters

The wrapper prevents changes to charts, research tables, public website
content and other non-Rappasoft tables.

## Deployment / verification

After this PR passes CI and is merged:

```bash
cd /var/www/brc_site
git status --short
git pull --ff-only origin master
docker exec brc_site php artisan view:clear
```

The new CSS is served as a static asset and is **not** generated by
Laravel Mix, so there is no `npm ci`, `npm run prod` or Composer
update needed for this PR.

Test Light, Dark and Auto (resolved) themes. Check User Management,
deactivated/deleted users, Role Management and both Broadcast tables.
Verify Livewire search, filters, sorting, Columns menu, pagination,
row actions and long/escaped names; then test responsive horizontal
scrolling on a narrow screen. The automated tests verify markup
presence, CSS scoping and HTML escaping, not pixel-level appearance.
